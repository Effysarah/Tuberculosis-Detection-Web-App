# Tuberculosis-Detection-App

Tuberculosis remains one of the top infectious disease killers worldwide, claiming over 1.6 million lives each year, according to the World Health Organization (WHO). It is especially prevalent in low-income regions where access to medical resources and timely diagnosis is limited. The consequences of delayed detection can be devastating, both in terms of patient outcomes and the spread of the disease.

# My Project: A Step Toward Accessible and Early Detection

To address this global health challenge, I developed a Tuberculosis Detection Web App that leverages deep learning, specifically a CNN model, to analyze chest X-rays for signs of TB. The web app provides a fast, accurate, and scalable solution to assist healthcare professionals in identifying potential TB cases. By automating the detection process, my solution aims to support quicker diagnoses, which is crucial for timely treatment and reducing transmission.

# Key Features of the Web App:

High Accuracy: The CNN model achieves over 92% accuracy, making it a reliable tool for detecting TB.

Scalable: Accessible through a simple web interface, the app can be used across various healthcare settings, from rural clinics to urban hospitals.

Image Enhancement: Techniques like histogram equalization, contrast stretching, and Gaussian filtering were used to improve the quality of X-ray images, leading to better detection performance.

# Impact: The potential for this tool to make a difference in underserved areas is immense, where TB is often diagnosed too late due to lack of resources.

The dataset used is from kaggle.com. I’m excited about the future and how technology like this can bridge gaps in healthcare access around the world.
